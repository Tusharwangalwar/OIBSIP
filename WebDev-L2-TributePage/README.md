
# Tribute Page — Dr. A. P. J. Abdul Kalam

## About the Project

This project is a responsive tribute webpage dedicated to Dr. A. P. J. Abdul Kalam, the renowned Indian aerospace scientist and former President of India.

The page highlights his life, professional journey, achievements, and inspiring message to students and young people.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Google Fonts

## Features

- Dark and cinematic visual design
- Responsive layout for desktop, tablet, and mobile
- Navigation links to About, Journey, and Legacy
- Biography section with multiple paragraphs
- Timeline of important milestones
- Inspirational quote section
- Consistent typography and gold accent colors
- Semantic HTML and descriptive image alternative text
- Smooth scrolling between sections
- Reduced-motion accessibility support

## How to Run

1. Download or clone the OIBSIP repository.
2. Open the `WebDev-L2-TributePage` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.
5. Resize the browser to test the responsive layout.

No build tools or package installation are required.

## Sections

3. Journey — timeline of milestones
4. Legacy — inspirational quote
