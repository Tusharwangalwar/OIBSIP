
# TaskFlow — To-Do Web App

## Project Overview

TaskFlow is a responsive task management web application built with HTML, CSS, and vanilla JavaScript. It helps users organize pending work, track completed tasks, and keep their task list saved in the browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser localStorage

## Features

- Add tasks with input validation
- Mark tasks as completed or pending
- Edit task names inline
- Delete individual tasks
- View pending and completed tasks separately
- Display pending, completed, and total task counts
- Clear all completed tasks after confirmation
- Persist tasks using localStorage
- Responsive dark-themed interface
- Keyboard-accessible buttons and input labels

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html` directly in a browser or use the Live Server extension.
3. Add a task using the input field.
4. Try editing, completing, and deleting tasks.
5. Refresh the page to confirm saved tasks remain available.

No package installation or build process is required.

## Storage Note

Tasks are stored in the browser's localStorage on the current device and browser. They are not synced to an account or server. Clearing browser site data may remove saved tasks.
