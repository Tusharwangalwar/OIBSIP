
# Calculator — OASIS INFOBYTE Level 2

## Overview
A responsive browser-based calculator built using HTML5, CSS3, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Number and decimal input
- Clear and backspace buttons
- Sequential operator chaining
- Division-by-zero error handling
- CSS Grid button layout
- Mouse and keyboard input
- No `eval()` or inline `onclick` handlers

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
Open `index.html` in a modern browser.
