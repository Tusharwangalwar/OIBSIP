
# Temperature Converter

## Overview
A responsive temperature conversion web application built for the OASIS INFOBYTE Web Development and Designing Internship, Level 1.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Converts Celsius, Fahrenheit, and Kelvin
- Displays all three units in the results
- Validates empty and invalid numeric input
- Rejects temperatures below absolute zero
- Responsive layout for desktop and mobile
- Clear labels and error messages
