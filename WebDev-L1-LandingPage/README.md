
# PixelCraft — Creative Portfolio Landing Page

## Project Overview
PixelCraft is a fictional creative web studio landing page created as part of the OASIS INFOBYTE Web Development and Designing Internship, Level 1.

The page presents creative services, studio information, example projects, and contact links through a clean, light-themed design.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Media Queries

## Features
- Sticky navigation bar
- Hero section with headline, description, and call-to-action
- Services section with three service cards
- About section
- Two featured project concept cards
- Contact section with email link
- Footer with placeholder social links
- Responsive desktop, tablet, and mobile layouts
- Smooth scrolling and keyboard focus styles
- No JavaScript or external frameworks

## How to Run
1. Download or clone the OIBSIP repository.
2. Open the WebDev-L1-LandingPage folder.
3. Open index.html in a web browser.

## Notes
PixelCraft and the featured projects are fictional concepts created for educational purposes. Replace placeholder contact and social details before presenting the project as your own portfolio.
